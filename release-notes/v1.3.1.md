# Checkpoint 1.3.1

- Color-coded priority tags: blue for Low, yellow for Medium, and red for High.
- Quick capture opens the priority picker without highlighting Medium or any other priority. Choose with 1/2/3, a click, or Tab and Enter.
- Priority colors also appear in the new-task selector and quick-capture choices.

Download `Checkpoint-1.3.1-Windows.exe` for the portable app or `Checkpoint-1.3.1-Setup.exe` for the installer. Existing users can install this release from Settings → Check for updates.
