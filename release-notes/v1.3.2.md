# Checkpoint 1.3.2

- Fix the updater reporting “The update installer exited before starting (0).”
- Launch the update worker in its own hidden Windows process so installation continues after Checkpoint closes.
- Correct installer exit-code handling and show verification errors from the installer helper.
- Release only the Windows installer and `SHA256SUMS.txt`.

## Updating from 1.3.0 or 1.3.1

Download and run `Checkpoint-1.3.2-Setup.exe` once. Quit Checkpoint from its tray menu before running the installer. The updater in those older versions cannot apply its own fix. Your saved tasks and settings are preserved. Future updates can be installed from Settings.
