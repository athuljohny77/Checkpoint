## Updates from GitHub

- Check for updates in Settings and read the latest release notes inside Checkpoint.
- Receive a system-tray notification when a newer stable version is available. Checkpoint checks shortly after launch and every six hours while running.
- Confirm before downloading and installing. Downloads are verified against the release's SHA-256 checksums.
- Portable updates replace the existing launcher at its current location and reopen Checkpoint. Tasks, preferences, and startup configuration are preserved. A `.previous` copy of the old portable launcher is retained.
- Installer users receive the matching Windows installer update.

## Downloads

- **Checkpoint-1.3.0-Windows.exe**: portable app, no installation required.
- **Checkpoint-1.3.0-Setup.exe**: Windows installer.
- **SHA256SUMS.txt**: download verification checksums.

Versions before 1.3.0 need this first update downloaded manually. Quit the old Checkpoint instance from its tray menu before opening the new version. Keep the portable EXE in a permanent, writable location.
